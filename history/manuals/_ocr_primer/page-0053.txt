Fancy Renumbering With REN
The following format for the REN command allows you to choose the starting line
number of the program. It also allows you to renumber a program with an incre-
ment other than 10. |
REN starting line number
REN starting line number, increment
To renumber the program so that it begins with line number 100, type:
REN 100
