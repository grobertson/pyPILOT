USING TYPE AND ACCEPT COMMANDS WITH STRING VARIABLES
String variables are defined by the interaction of TYPE and ACCEPT commands.
The ACCEPT command, A:, followed by a string variable name defines the string
variable and saves the input as its value in memory. |
10 T: WHAT IS YOUR NAME?
20 A: $NAME
30 T: WHERE DO YOU LIVE?
40 A: $ADDRESS
