If there is a match, MS: divides the input into three pre-named string variables: |
$LEFT, $MATCH, and $RIGHT:
$LEFT is the value of everything to the left of the matched item
$MATCH is the value of the matched item
$RIGHT is the value of everything to the right of the matched item |
This example program demonstrates how the MATCH STRING command divides
input into three variables:

60 T: THE RIGHT VARIABLE IS: $RIGHT

The ability to separate a single string into three separate strings makes MATCH |
STRING a very powerful command. You can use it to rearrange your string input,
discard portions of your input, and so on.
SENSING A MATCH i
When the ACCEPT and MATCH strings are evaluated for a successful or unsuc-
cessful match, the condition is remembered as true or false in the computer's
memory. You can display the MATCH SENSING variable to find out if the match is
true or not. i
