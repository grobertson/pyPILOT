The DRAWTO Subcommand s
| The DRAWTO subcommand moves the turtle from the current cursor position to the
specified point while drawing a line. The point is defined by an (X,Y) coordinate
pair.
| The format for the DRAWTO subcommand is:
GR: DRAWTO X,Y
where: X is the X-axis coordinate
Y is the Y-axis coordinate
Examples:
| GR: DRAWTO 15,35
GR: DRAWTO #J,#K/2
| The line is drawn in the color of the current pen color. If the pen is UP, then no line
is drawn.
The following program draws a box using the PEN and DRAWTO subcommands.
| Clear memory and type:

20 GR: PEN BLUE; DRAWTO 20,20
