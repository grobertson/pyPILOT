To delete a line from a program, type the line number and press the key.
This erases the line from the program in memory, but not from the screen display
until the program is LISTed.
To insert a line into a program, enter it using a new line number. The new number
must fall between the line numbers where the line is to be inserted. The screen will
not show the inserted line in its correct position until the program is LISTed. |
There are two methods to replace a line. Delete the old line and insert a new line
using the same line number. Or, simply assign the new line the old line number. ’
The change will not be shown on the screen until the program is LISTed.
