conditionally, depending upon the success of a match between an ACCEPT and
MATCH string. Modules can be called conditionally also by changing the USE com-
mand to a USE IF YES or USE IF NO command. |
These commands have the format:
UY: module label
UN: module label |

one of these commands will be executed. If both are present, one will be bypassed. J
