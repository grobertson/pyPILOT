| SENSING THE JOYSTICK’S TRIGGER
The value of the joystick trigger sensing variables, %T8, %T9, %T10, and %T11
depends upon whether or not the trigger is pressed:
| 0 if trigger is up
1 if trigger is pressed
| If pressure on the trigger is not sensed within 5/60 of a second after it was last pressed,
the trigger variable value becomes 0.
Below is an example of how the four trigger sensing variables work. The value in
the box is the sensing variable’s value:
