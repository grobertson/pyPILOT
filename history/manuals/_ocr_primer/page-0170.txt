Merging Programs
| & Programs can be merged when loading off a diskette and into memory. Merge
means to blend together or combine. If you have a program in memory, and you
load another program from a diskette into memory without clearing memory first,
the two programs will merge. If both programs use the same line numbers, the
| statements loaded off the diskette have priority and are remembered.
Merging programs can be advantageous or disastrous. Used correctly, you can ex-
| pand a current program by merging another program into it.
