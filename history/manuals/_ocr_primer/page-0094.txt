THE COMPUTE IF YES AND COMPUTE IF NO COMMANDS, CY:, CN:
| The COMPUTE command may be used with yes or no conditioners to make COM-
PUTE conditional upon a match or no match.
| The formats for the COMPUTE IF YES and COMPUTE IF NO commands are:
CY: variable name = value
| CN: variable name =value
A MATCH command must precede the CY: or CN: command. If the match is suc-
cessful, the CY: command is executed (e.g., CY: $VAR=CAT). If the match is un-
successful, the CN: command is executed (CN: $VAR= DOG). If both commands
follow the same MATCH command, only one will be executed. The other com-
mand is bypassed.
