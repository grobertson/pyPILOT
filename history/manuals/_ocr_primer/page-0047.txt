® Continuing Text With the Backslash Character: PILOT uses a special character |
that keeps the cursor from dropping to the next line. This character is the
backslash, \, produced by pressing the key and the \ + key. When the com-
puter encounters a backslash at the end of a TYPE command, the cursor stops and
waits ON THE PRESENT LINE instead of doing a carriage return. Any following text a |
will be displayed from that point. The program below uses the backslash:
