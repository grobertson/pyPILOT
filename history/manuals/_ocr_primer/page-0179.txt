Merging Programs
When loading a program from a cassette tape, you can merge, or combine, the pro-
gram on tape with the current program in memory.
For more information about merging programs, refer to “Merging Programs’’ under
“Loading Programs From a Diskette.’’
@ To avoid accidentally merging two programs, always type NEW before
loading a program. @
A Method To Manage Programs on Cassette Tapes
This section describes how to save up to 30 programs on one cassette and create a
program directory.
This method centers on the program listed on the following pages. This program is
designed to function as a directory within the cassette tape. It allows you to enter
the program names saved on the tape and their corresponding counter numbers.
Later, you can look up the program name and its counter number and advance the
tape to its starting point.
