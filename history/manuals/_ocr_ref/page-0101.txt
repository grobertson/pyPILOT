You can make any PILOT command (T:, A:, M:, J:, C:, U:, E:, GR:, SO:, and PA:)
conditional on a YES-match or NO-match by putting a Y or an N between the command
and the colon (:). Here are some examples:
TY:HELLO If there is a match, type “HELLO”; otherwise, skip this
command.
TN:WRONG If no match, type “wrong”; otherwise, skip this command.
Ye If there is a match, end the program; otherwise, keep going.
JN: # NEXT If no match, jump to %* NEXT; otherwise, skip this command.
UY: # BOX If there is a match, use the module % BOX; otherwise skip this
command.
S SOY:13,17 If there is a match, sound notes 13 and 17; otherwise skip this
command.
